# 海岛 / 阳光装扮素材（果冻海系列）

- **来源**：Unsplash（[License](https://unsplash.com/license)）与 Pexels（[License](https://www.pexels.com/license/)）— 可免费商用
- **拉取脚本**：`scripts/fetch_island_theme_assets.py`（`--force-themes` 强制重下 20 套 cover/bg）
- **清单**：`scripts/island_theme_assets_manifest.json`
- **用途**：站点装扮「海岛/阳光」主题包；每套 cover 为唯一主视觉（缩略图与全站背景同源，`bg` 与 cover 保持同图以防缓存/旧路径）

## 选图标准（须同时具备）

1. 热带海岛 / 沙滩  
2. 晴天阳光（明媚，非纯剪影黄昏）  
3. 椰子树或明显棕榈  
4. 清澈浅海（玻璃海 / 果冻海：碧绿或 Tiffany 蓝）

禁止：圣托里尼/爱琴蓝白、雪山湖、温带码头、纯水下鱼群、汉达拉门等错配当封面。

请勿替换为未授权商用图或私站盗链。
